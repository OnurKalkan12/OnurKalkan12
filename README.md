# Hi, I'm Onur 👋

I work where support, operations, and infrastructure meet. I spent years on the customer side of online products, ran a 24/7 support team, and then moved into Linux administration for a payment service provider. Today, I build small tools and automations that take manual work off people's plates.

Based in Berlin.

## What I work with

- **Linux and infrastructure:** Debian, Proxmox, Nginx, networking, VPN, firewalls, Docker, AWS
- **Automation:** Terraform, Ansible, Bash, Python, n8n, GitHub Actions
- **Support and troubleshooting:** APIs and integrations, logs, reproducing issues, clear bug reports
- **Security and compliance:** PCI DSS, OSSEC, server hardening
- **Building with AI:** I build with Claude Code and start every feature from a written spec

## Projects

- **[homelab-infra](https://github.com/OnurKalkan12/homelab-infra)**: my Proxmox homelab as code. Terraform provisions it, Ansible configures it, and GitHub Actions validates every change. Networks are split into VLANs, and an observability stack with Prometheus and Grafana is in progress.
- **[geekspic-tg-alerts](https://github.com/OnurKalkan12/geekspic-tg-alerts)**: a Python pipeline that collects news from RSS feeds, removes duplicates with SQLite and sends new items to Telegram on a daily GitHub Actions schedule. Built step by step for a small content team.
- **Salvo** (private): a multi-tenant customer messaging and shared support inbox for small businesses, built with Node.js and deployed with Terraform, Ansible and CI. I built it, sold it to a business customer and onboarded them. Happy to walk through it on a call.
- **[ossec-hids-usage](https://github.com/OnurKalkan12/ossec-hids-usage)**: my notes on running OSSEC host intrusion detection with a manager and agents.
